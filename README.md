# 🩺 MediMate

**MediMate** is a clean, reliable full-stack platform designed to bridge the gap between patients and pharmacies. It simplifies how patients manage their prescriptions and recurring medicine refills while giving pharmacists a streamlined console to handle inventory, review prescriptions, and manage orders.

Instead of feeling like a generic medical portal, MediMate is built to handle the real-world workflow of prescription verification, recurring monthly refills, and transparent order tracking.

---

## 🚀 Key Features

### For Patients 🙋‍♂️
* **Smart Catalog:** Browse OTC and prescription-only medicines with pricing clearly shown in PKR.
* **Easy Uploads:** Upload doctor prescriptions directly to get a quick quote and order setup.
* **Set & Forget Refills:** Subscribe to recurring medicine deliveries (like monthly insulin or blood pressure pills) so you never run out.
* **Visual Order Tracker:** See exactly where your order is in real-time, from pharmacy review to delivery.
* **Saved Profiles:** Keep your address and contact details saved for one-click checkouts.

### For Pharmacists 🥼
* **Verification Queue:** A simple inbox to review uploaded prescriptions and securely approve or reject them.
* **Billing Console:** Update order quotes, adjust medicines, and finalize pricing.
* **Order Pipeline:** Seamlessly manage incoming orders through clear stages (*Approve → Dispatch → Deliver*).
* **Subscribers Catalog:** View all patient refill subscriptions in one place with options to pause, resume, or cancel them.

---

## 🛠️ Tech Stack

* **Database:** PostgreSQL
* **Backend:** Node.js + Express.js
* **Frontend:** React.js + Vite
* **Styling:** Vanilla CSS 
* **Authentication:** Cookie-based JWT sessions
